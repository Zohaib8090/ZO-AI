Before you start
  • What this is. ZO-AI on the web is the assistant built into Zohara OS. Here it can chat, search the web and keep notes about you (memory).
  • Where your data goes. Your chats and memory are stored in the cloud (Google Firebase) under your own account, so they follow you between the web, the desktop app and the terminal. The person who runs this service can technically access the database. Do not put sensitive secrets in chats.
  • Your own API key. You bring your own key from an AI provider. It is stored encrypted on our server and only used to call that provider for you.
  • No access to your computer. The web version cannot see or control your computer. Computer-control tools run only in your own desktop app, which can sync its chats here.
  • You can export or delete everything at any time in Settings > Account.
